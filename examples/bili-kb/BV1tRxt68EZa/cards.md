## 四个基本子空间的维数
- 类型：fact｜置信度：high｜来源：agent
- 标签：四个基本子空间、左零空间、零空间
- 结论：列空间 r、行空间 r、零空间 n-r、左零空间 m-r（m 行 n 列，秩为 r）。
- 为什么：这四个维数把 Ax=b 的可解性与唯一性完全刻画清楚。
- 怎么做：
  1. 列空间与行空间维数都等于 r
  2. 零空间维数 = n - r
  3. 左零空间（A 转置的零空间）维数 = m - r
- 证据（可回跳原视频）：

  - [02:22] 左零空间的维数是 m 减 r，m 是行数 → https://www.bilibili.com/video/BV1tRxt68EZa?t=142

## 秩-零化度定理与正交性
- 类型：concept｜置信度：high｜来源：agent
- 标签：秩-零化度定理、正交
- 结论：秩 + 零度 = n；且列空间与零空间在 R^n 中互相正交。
- 为什么：它把「解空间的维数」变成一次化简就能得到的数，并给出几何图像。
- 怎么做：
  1. 求 Ax=0 的通解，自由变量个数即零度 n-r
  2. 检查列空间与零空间的正交性（每个主元列与解向量点积为 0）
- 证据（可回跳原视频）：

## 求四个子空间基的三步流程
- 类型：procedure｜置信度：high｜来源：agent
- 标签：计算步骤、基
- 结论：先化简数主元得 r，再回代求零空间基，最后对 A 转置重复同样两步得到左零空间基。
- 为什么：三步覆盖四个子空间，不需要额外技巧，是可直接执行的算法。
- 怎么做：
  1. 行阶梯形 → 主元列 → 回到原矩阵取那些列作为列空间的基
  2. 回代求 Ax=0 通解，自由变量逐个置 1 得到零空间基
  3. 对 A 转置做同样两步得到左零空间的基

## 行变换改变列空间，但不改变列之间的线性关系
- 类型：caution｜置信度：high｜来源：agent
- 标签：行变换、列空间、易错点
- 结论：行变换会改变列空间本身，却保持列之间的线性关系，所以主元列要回到原矩阵去取。
- 为什么：直接把行阶梯形的列当成列空间的基是常见错误，会得到错误的向量。
- 怎么做：
  1. 用行化简定位主元列的下标
  2. 回到原矩阵取相同下标的列作为基
- 证据（可回跳原视频）：
  - [04:24] 行变换会改变列空间，但不会改变列之间的线性关系 → https://www.bilibili.com/video/BV1tRxt68EZa?t=264
  - [04:44] 用行化简找出哪些列是主元列，再回到原矩阵取那些列，才是列空间的基 → https://www.bilibili.com/video/BV1tRxt68EZa?t=284

## 求零空间基时自由变量要逐个置 1
- 类型：caution｜置信度：high｜来源：agent
- 标签：零空间、易错点
- 结论：写零空间的基时，一次只让一个自由变量为 1，其余为 0，不能全部同时置 1。
- 为什么：全部置 1 会得到一个解向量而不是基，维数与线性无关性都不对。
- 怎么做：
  1. 列出自由变量下标
  2. 对每个自由变量分别令其为 1、其余自由变量为 0，解出一个基向量
- 证据（可回跳原视频）：
  - [04:05] 求零空间的基时把自由变量全设成 1，正确做法是一次只让一个自由变量为 1 → https://www.bilibili.com/video/BV1tRxt68EZa?t=245

## 满秩与 Ax=b 的解的情况
- 类型：fact｜置信度：high｜来源：agent
- 标签：满秩、可解性
- 结论：秩 = 行数 m 时 Ax=b 对任意 b 都有解；秩 = 列数 n 时 Ax=b 至多一个解。
- 为什么：前者因为列空间等于整个 R^m，后者因为零空间只剩零向量。
- 怎么做：
  1. 先求秩 r
  2. r = m → 任意 b 可解
  3. r = n → 解唯一或无解
- 证据（可回跳原视频）：
  - [05:02] 如果秩等于行数 m，那么 Ax=b 对任意 b 都有解，因为列空间就是整个 R^m → https://www.bilibili.com/video/BV1tRxt68EZa?t=302
  - [05:20] 如果秩等于列数 n，那么 Ax=b 至多一个解，因为零空间只剩零向量 → https://www.bilibili.com/video/BV1tRxt68EZa?t=320
