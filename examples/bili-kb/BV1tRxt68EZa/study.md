## 自测提问（按卡片生成，回答后再 bili_practice grade 记录）

- [rank-def] 秩 = 行阶梯形里的主元个数 → 请解释：矩阵的秩就是它化成行阶梯形后主元的个数，必须先化简再数。（依据：00:14 处讲解）
- [four-subspaces] 四个基本子空间的维数 → 请解释：列空间 r、行空间 r、零空间 n-r、左零空间 m-r（m 行 n 列，秩为 r）。（依据：02:40 处讲解）
- [rank-nullity] 秩-零化度定理与正交性 → 请解释：秩 + 零度 = n；且列空间与零空间在 R^n 中互相正交。（依据：01:36 处讲解）
- [compute-procedure] 求四个子空间基的三步流程 → 请解释：先化简数主元得 r，再回代求零空间基，最后对 A 转置重复同样两步得到左零空间基。（依据：02:58 处讲解）
- [row-ops-columns] 行变换改变列空间，但不改变列之间的线性关系 → 请解释：行变换会改变列空间本身，却保持列之间的线性关系，所以主元列要回到原矩阵去取。（依据：04:24 处讲解）
- [free-variables] 求零空间基时自由变量要逐个置 1 → 请解释：写零空间的基时，一次只让一个自由变量为 1，其余为 0，不能全部同时置 1。（依据：04:05 处讲解）
- [full-rank-solvability] 满秩与 Ax=b 的解的情况 → 请解释：秩 = 行数 m 时 Ax=b 对任意 b 都有解；秩 = 列数 n 时 Ax=b 至多一个解。（依据：05:02 处讲解）
