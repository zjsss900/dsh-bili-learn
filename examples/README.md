# 示例产物（不是真实学习记录）

这份 `bili-kb` 样例是用**合成讲稿**跑出来的：讲稿文件是 `.fixtures/linear-algebra-rank.txt`（我手写的线性代数讲解，带 `[mm:ss]` 时间戳），视频链接是真的（BV1tRxt68EZa，235 秒），但时间戳与真实视频**不对应**。

留着它只为看产物格式：`source.json` 的覆盖度、`segments.json` 的 `unread` 状态、`cards.md` 的证据链、`study.md` 的自测提问。

`source.json` 里 `transcriptSource` 记的是 `user-text`， provenance 是诚实的。真实使用请给登录态或真实文稿，插件不会替你编造讲稿。
